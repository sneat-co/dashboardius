Inside the board

The technology behind Dashboardius

A tech stack is the languages, libraries and services used to build a product. Dashboardius brings charts, tables and narrative cards into one board, with a prototype model inspired by DataTug's board design.

The interface

Angular renders the interactive board. Angular CDK handles card movement; Chart.js draws visual trends; AG Grid and Tabulator display query-shaped tables. PrimeNG supplies bounded interface controls. Each library has a specific job, while the board keeps cards in one twelve-column layout.

The data model

The current public board is an in-memory demonstration with invented numbers, and labels them as demo data. Its card definition is local to this prototype; DataTug owns the durable board contract. Real saving, sharing, GitHub commits and a persistent dashboard service are still planned.

This website

The homepage is prerendered to HTML at build time and then hydrated for interaction. Cloudflare Workers static assets serve it; there is no Dashboardius backend in the current release.
